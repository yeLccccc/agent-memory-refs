Google 开源 Harness²：让 Agent 自己改脚手架 · 参考资料

公众号「拉普拉斯大魔王」RSI 深读 · 01。正文外链被微信剥除，可点击版全部在本页；事实口径截至 2026-11-05。
数据口径与可靠性说明：① 本文全部实验数字为论文自报（arXiv 2610.14224v1，2026-10-09 提交，未经独立审计）；判分虽由基准方协议的第三方模型完成（WorkBuddy 复合验证器、JobBench 用 Claude Opus 4.8 按加权 rubric、Harvey LAB 用 Claude Sonnet 4.6 按 per-criterion 通过率），rubric 不向改进管线暴露，但仍无外部复现。② 仓库 README 自述 "This is not an officially supported Google product"——研究开源，非产品发布。③ 中文圈「Gemini 3.5 性能暴涨」等说法查无一手出处，本文未采用。④ 「弱模型 + 改过的脚手架反超强模型」的对照是同基准同判分下的均值比较（GLM-5/OpenCode 改后 75.7 vs Gemini 3.5 Flash/OpenCode 原始 72.4），不是跨基准结论。⑤ 编辑器/选择器全程为 Claude Opus 4.8，执行器为 GLM-5 与 Gemini 3.5 Flash（各配 OpenCode / Codex）。
